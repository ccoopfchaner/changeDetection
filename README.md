# 葡萄疏果关键帧标注查看器

本仓库仅发布学生使用的静态网页与标注说明，不包含视频、任务Excel、学生标注、研究结果或模型权重。

GitHub Pages配置完成后的入口：https://ccoopfchaner.github.io/changeDetection/

## 学生怎样使用

1. 下载并解压老师另外发放的视频资料包和Excel填写表。
2. 打开上述网站，先阅读标注说明，再选择本机上的原始MP4。
3. 使用0.1/0.25/0.5倍速、回放前2秒、指定区间循环、逐帧前进后退，确认果粒剪落到消失的可见过程。
4. 将已确认的源帧号填入Excel。回放区间只是观察窗口，不自动成为PNR标签。

本批视频限定恒定30fps，按原视频从1开始的源帧号记录。只接受老师发放并登记的视频文件名和字节大小，避免误用转码、裁剪或网盘预览版本。

## 视频不上传

文件选择框使用浏览器File/Blob接口读取本地视频，不向服务器上传内容。网页没有账号、标注收集、分析统计、第三方脚本或外部字体；查看器的Content Security Policy禁止网络连接与表单提交。

正常访问网页仍会向GitHub Pages请求页面，这是网站托管所需的访问，不代表视频上传。网页不保存标签，关闭或刷新前请自行保存Excel。

## 解码兼容性

原视频为4K HEVC，学生浏览器需要具备该编码的解码能力。网站能打开，不保证所有设备能播放HEVC。黑屏或一直没有“已显示源帧”时应停止标帧并联系老师；不能凭时间条猜测，也不要自行转码。

如以后发放H.264兼容副本，教师必须先核验与源视频帧数和时间逐帧对应，并更新该副本的文件校验信息。当前网页没有把未经核验的转码文件视为原视频。

## 标注约定

本任务中的PNR是“可见剪离/脱落至被剪果粒消失”的帧段，不直接等同于Ego4D的单帧PNR。PRE/POST各段不超过30帧，重点帮助确认哪颗果粒消失；缺失时留空并备注。完整规则见网页“标注说明”。

## 部署与检查

使用GitHub Pages的Deploy from a branch，来源为main分支根目录，不需要第三方构建服务或密钥。默认只发布本仓库网页，不设置视频公网地址，不自动收集学生信息。

静态检查：`node --test tests/static.test.cjs`。该检查核验语法、原视频白名单与无上传逻辑，不替代实际设备的HEVC解码和精确帧显示检查。
